# Tumlo

Tumlo is a fork of [Spotifast](https://github.com/crmne/spotifast). For the
original project's overview, features, and setup instructions, see the
[Spotifast README](https://github.com/crmne/spotifast#readme).

This fork adds Jellyfin as a provider alongside Spotify. See the
[Jellyfin fork notes](docs/_reference/jellyfin-fork.md) for its current status.
