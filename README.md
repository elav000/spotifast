# Tumlo

Tumlo is a fork of [Spotifast](https://github.com/crmne/spotifast). For the
original project's overview, features, and setup instructions, see the
[Spotifast README](https://github.com/crmne/spotifast#readme).

This fork adds Jellyfin as a provider alongside Spotify. When Tumlo reopens in
**All providers**, it shows the combined catalog while your saved accounts and
configured Spotify player prepare in the background. See the
[roadmap](ROADMAP.md) for the current status.
